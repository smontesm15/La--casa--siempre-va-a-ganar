# La casa siempre va a ganar
Loop Casino es un proyecto interactivo en línea que ofrece una exploración narrativa acerca de la ilusión de control en sistemas digitales. El usuario es invitado a participar en una experiencia que simula un casino, donde puede tomar decisiones libres y ganar o perder, aparentemente. No obstante, a medida que se desarrolla el sistema, muestra su naturaleza manipulada al crear un ambiente donde todas las acciones llevan a una misma conclusión.

El proyecto se desarrolla a través de un recorrido de varias páginas que combina diversas lenguas visuales e interactivas, yendo de una interfaz minimalista y vacía a una estética seductora y estimulante. Este cambio representa un punto de inflexión en la experiencia, en el que el usuario empieza a identificar la repetición y el ciclo del que está prisionero y deja de ver al sistema como un juego.

Se implementan métodos de interacción, manipulación del DOM y almacenamiento local con la ayuda de tecnologías web como CSS, JavaScript y HTML para crear una narración no lineal que reacciona a las acciones del usuario. El objetivo del proyecto no es solo que se entienda, sino también que se experimente y que produzca una reflexión sobre la frustración, los límites de control y la repetición en el ámbito digital.
